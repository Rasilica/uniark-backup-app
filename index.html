uniark-backup

uniark-backup은 UNIARK 운영자가 자기 서버의 데이터베이스와 파일을 운영자 본인의 Google Drive에 암호화해 백업하는 내부 도구입니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

uniark-backup is an internal tool the UNIARK operator uses to back up its own server database and files, encrypted, to the operator's own Google Drive. It is not offered to the public.

  • Google 권한: drive.file 하나만 사용합니다. 이 도구가 직접 만든 파일과 폴더에만 접근하며, Drive의 다른 파일은 보거나 바꿀 수 없습니다.
  • Google permission: only drive.file. The tool can access only files and folders it created, never other Drive content.
