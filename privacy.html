개인정보처리방침

시행일: 2026-10-12

uniark-backup은 UNIARK 운영자 한 명이 자기 서버를 백업하려고 쓰는 내부 도구입니다.

  • 접근하는 데이터: Google drive.file 권한으로, 이 도구가 운영자의 Google Drive에 만든 백업 폴더와 파일에만 접근합니다. 다른 Drive 파일, 연락처, 메일 등은 읽지 않습니다.
  • 사용 목적: 운영자 서버의 백업 파일을 올리고, 보관 기간이 지난 백업을 지우고, 복구할 때 내려받는 데만 씁니다.
  • 저장·공유: 백업은 올리기 전에 서버에서 암호화합니다. Google 인증 토큰은 운영자 서버에만 저장하며, 누구에게도 제공하거나 판매하지 않습니다. 광고나 분석에 쓰지 않습니다.
  • 권한 철회: Google 계정의 서드파티 액세스에서 언제든 철회할 수 있습니다.
  • 문의: noah@uniark.art

uniark-backup의 Google API 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

Privacy Policy

Effective: 2026-10-12

uniark-backup is an internal tool used by a single UNIARK operator to back up its own server.

  • Data accessed: With the Google drive.file scope, it accesses only the backup folders and files it created in the operator's Google Drive. It does not read other Drive files, contacts, or mail.
  • Use: Solely to upload server backups, delete backups past their retention period, and download them for restores.
  • Storage and sharing: Backups are encrypted on the server before upload. The Google OAuth token is stored only on the operator's server and is never shared or sold. No advertising or analytics use.
  • Revoking access: At any time via Google Account third-party access.
  • Contact: noah@uniark.art

uniark-backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
